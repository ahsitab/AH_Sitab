## ✨ Features

- 🌗 **Dark / Light Mode** toggle with smooth transitions
- 🎨 **Theme Colour Picker** — Blue, Purple, Green accent options
- 🖼️ **Auto-sliding Profile Slideshow** with crossfade animation
- 💬 **Animated smoke / particle canvas** background effect
- 🖱️ **Custom animated cursor** (dot + outline)
- 📱 **Fully responsive** across mobile, tablet, and desktop
- 🔗 **Smooth scroll** navigation with active link highlighting
- ❓ **FAQ accordion** section with animated expand/collapse
- 🎯 **Glassmorphism** card design language throughout
- ⚡ **Zero dependencies** — pure HTML, CSS, JS (no frameworks)

## 🚀 Running Locally

### Option 1 — VS Code Live Server (Recommended)
1. Open the project folder in VS Code
2. Install the **Live Server** extension
3. Right-click `index.html` → **Open with Live Server**
4. Site opens at `http://127.0.0.1:5500`

### Option 2 — Python HTTP Server
```bash
# Python 3
python -m http.server 8080
# Then open http://localhost:8080
```

### Option 3 — Node.js HTTP Server
```bash
npx serve .
# Then open the URL shown in the terminal
```
